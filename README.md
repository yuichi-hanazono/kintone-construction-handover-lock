# kintone 案件（工事）引渡日ロック

案件（工事）アプリで、引渡日が保存された案件の引渡日・売上・原価を編集不可にするJavaScriptカスタマイズです。

アプリIDはJSに固定していません。そのため、本番アプリ（アプリID `10`）をコピーしたテストアプリ（アプリID `314`）にも同じファイルを登録できます。

## 対象フィールド

| 項目 | フィールドコード |
| --- | --- |
| 引渡日 | `construction_complete_date` |
| 売上 | `order_amount` |
| 原価 | `cost_amount` |

## 動作

- 新規入力中は、引渡日を修正できます。
- 入力中の引渡日に値がある間は、売上と原価を編集不可にします。
- 入力中に引渡日を空欄へ戻した場合、売上と原価を編集可能に戻します。
- 保存済みレコードの編集画面を開いた時、引渡日が入力済みなら3項目すべてを編集不可にします。
- PC版の一覧インライン編集でも同じロックを適用します。
- PC版・モバイル版の追加／編集画面に対応します。
- ロック済みレコードの3項目が保存時に変更されていた場合は、保存を拒否します。

## ロック解除

引渡日が入力済みの詳細画面で、次のユーザーにだけ「引渡日ロック解除」ボタンを表示します。

- `yuichi-hanazono@saneki.co.jp`
- `naoya-yamaguchi@saneki.co.jp`

確認後、引渡日だけを空欄にして保存します。売上と原価の値は保持します。更新に成功すると詳細画面を再読み込みします。

解除ユーザーには、対象アプリのレコード編集権限および引渡日フィールドの編集権限が必要です。

この2名の判定は、カスタマイズ画面上のボタン表示とクリック処理に対する制御です。kintone JavaScriptはブラウザー画面のカスタマイズであるため、REST API、CSV取込、別の連携プログラムによる更新まで禁止するものではありません。厳密に変更を禁止する場合は、対象ユーザーのアプリ／レコード／フィールド権限と、外部連携側で3項目を更新しない運用も設定してください。

## kintoneへの登録

`src/kintone-construction-handover-lock.js` を、案件（工事）アプリのJavaScript／CSSカスタマイズへ登録します。

- PC用JavaScript：`src/kintone-construction-handover-lock.js`
- モバイル用JavaScript：同じファイル

本番登録前に、テスト用アプリまたはテストレコードで以下を確認してください。

1. 引渡日が空欄のレコードで3項目が編集できること
2. 引渡日入力中に売上・原価が編集不可になること
3. 引渡日を空欄に戻すと保存前は売上・原価が編集可能に戻ること
4. 引渡日保存後、再編集時に3項目すべてが編集不可になること
5. 一覧インライン編集で同じ制御になること
6. モバイル編集画面で同じ制御になること
7. 指定ユーザーだけ解除ボタンを操作できること
8. 解除後に引渡日が空欄となり、次回編集時に3項目が編集可能になること

売上と原価が計算フィールドの場合は、kintoneの仕様上、JavaScriptで編集可否を切り替える対象外です。実際のフィールド形式と、既存のJavaScript／プラグインとの競合も本番登録前に確認してください。
